# Acuarios Shop — Inventario, Ventas y Catálogo

Aplicación web todo-en-uno para la gestión diaria de **Acuarios Shop**:

- **1. Vender (Caja Rápida):** carrito de compras, facturación en Dólares (`$`) y Bolívares (`Bs`), formas de pago, devolución/anulación de ventas y cierre diario copiable para WhatsApp.
- **2. Inventario:** control de stock, alertas de pocas unidades/agotadas, edición rápida y exportación a CSV (Excel).
- **3. Ropa Nueva:** alta individual o por lote surtido de tallas/colores con calculadora automática de costo unitario y margen de ganancia.
- **4. Foto Catálogo:** estudio de fotos con fondos limpios y etiqueta de precio/talla descargable en PNG.
- **5. Tasas del Día:** gestión de tasas (BCV, Euro BCV, Binance USDT y Promedio) con conversor instantáneo.

## Cómo probarla

- **Local:** abre `index.html` directamente en tu navegador.
- **GitHub Pages:** activa Pages en *Settings → Pages → Branch: `main` (`/ (root)`)* para acceder desde `https://abeldesigns.github.io/Acuarios-Shop-Inventario/`.
